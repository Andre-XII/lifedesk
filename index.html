Come si installa

Android

  1. Tocca Scarica per Android e apri il file scaricato.
  2. Se richiesto, consenti “Installa app da questa fonte” al browser.
  3. Conferma l'installazione. Se compare un avviso di Play Protect scegli “Installa comunque”.
  4. Gli aggiornamenti successivi li scarichi direttamente dall'app.

Windows

  1. Scarica ed esegui LifeDesk-Setup.exe.
  2. Se Windows mostra “SmartScreen”: Ulteriori informazioni → Esegui comunque.
  3. Scegli se installare solo per te o per tutti gli utenti.
  4. Gli aggiornamenti successivi si installano dall'app, con un clic.
